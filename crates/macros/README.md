# redis-module-macros

Command attributes, INFO helpers and reply derives for authors using `redis-module`.
The shared metadata dependency is supplied by `redis-module-common`.

This development fork has unpublished local changes; package metadata retains
the inherited names and versions. See the
[repository](https://github.com/joshrotenberg/redismodule-rs) for the workspace.
